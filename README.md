# Credit-Decision-Agent

Automating credit insights extraction from unstructured financial data using LLMs and LangChain.

## Features
- Parse bank statements and credit reports
- Generate standardized risk profiles
- Integration with lending decision systems

## Tech Stack
- Python
- LangChain
- LLMs (e.g., OpenAI, Grok)
- Pandas for data handling

## Setup
1. Clone the repo
2. Install dependencies: `pip install langchain openai pandas`
3. Set API keys
4. Run the agent

## Outcome
Reduced manual review time by 65%.
